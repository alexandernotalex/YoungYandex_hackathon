Прямоугольный опенспейс состоит из блоков в форме квадратов. Ровно в одном блоке стоит кулер с водой (обозначается буквой “W”), в некоторых блоках находятся рабочие места сотрудников (обозначаются буквой “E”), а некоторые блоки свободны (обозначаются символом “.”). За одну секунду сотрудник может переместиться в соседний по стороне блок. Сотрудники перемещаются к кулеру по кратчайшему пути, они могут проходить через любые блоки (в том числе, в которых находятся рабочие места сотрудников).
